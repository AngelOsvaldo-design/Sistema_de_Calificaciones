# Sistema de Calificaciones en Python 

Este proyecto es una aplicación desarrollada en **Python** diseñada para gestionar, analizar y procesar un conjunto de calificaciones escolares mediante el uso de estructuras de datos lineales (**vectores o arreglos**).

El código demuestra de forma práctica conceptos fundamentales de programación como el manejo de índices, operaciones estadísticas, estructuras condicionales y bucles de repetición.

---

## 🚀 Características del Programa

* **Listado dinámico:** Muestra todas las calificaciones almacenadas junto con la identificación de cada estudiante utilizando índices (`enumerate`).
* **Acceso por índice:** Permite consultar la calificación de un estudiante específico de manera directa.
* **Estadísticas automáticas:** Calcula el promedio general del grupo, además de identificar la calificación más alta y la más baja mediante funciones integradas (`sum`, `len`, `max`, `min`).
* **Evaluación de rendimiento:** Cuenta la cantidad de estudiantes aprobados y reprobados aplicando una estructura condicional (`if/else`) basada en una nota mínima aprobatoria de 70 puntos.
* **Modificación de datos:** Permite actualizar una calificación específica utilizando su índice y recalcula de forma inmediata las métricas del grupo.
